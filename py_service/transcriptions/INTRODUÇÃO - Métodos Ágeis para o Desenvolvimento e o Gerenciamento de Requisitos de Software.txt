Título: INTRODUÇÃO - Métodos Ágeis para o Desenvolvimento e o Gerenciamento de Requisitos de Software
----------------------------------------
 Agile. Se você trabalha ou estuda tecnologia, software ou design, em algum momento você vai se deparar com esse termo. Mas o que significa ser ágil? E o que são os chamados métodos ágeis? Como eles são utilizados? E se você se deparou com os métodos ágeis por ter interesse em software, você também vai se deparar com os chamados requisitos. E o que são os requisitos? Como eu encontro eles? E o que eu faço com eles? O que aquelas perguntas tem a ver com essas perguntas? O objetivo desse curso é responder esses e outros questionamentos usando exemplos de dois métodos ágeis específicos, os métodos React e ReactM. Meu nome é Andrei Amaral e junto com o professor Sandro Bezerra, coordenador do projeto SpiderUFC, nós criamos esse curso para conversar e mostrar um pouco da relação entre métodos ágeis e requisitos de software. Aliás, esse curso foi criado como parte do projeto de extensão Transferência de Conhecimento de Métodos Ágeis para a Elicitação e Especificação de Requisitos de Software, que foi executado na Universidade Federal do Pará com financiamento da Pró-Reitoria de Extensão por meio do edital Navega Saberes de 2023. . Nós estudamos o método React e ReactM, que é um método que é utilizado para a produção de dados e dados de dados. Nós estruturamos esse curso em seis módulos. No módulo 1, apresentamos um breve nivelamento de conceitos básicos. No módulo 2, nós apresentamos métodos React e ReactM. No módulo 3, vemos a concepção de um produto de software usando a inception, que é uma das etapas dos métodos anteriores. No módulo 4, nós vamos entender como encontrar os requisitos desse produto concebido, usando a técnica de IOS. No módulo 5, nós vamos entender como encontrar os requisitos desse produto e no módulo 6, nós vamos aprender como visualizar os diferentes níveis de requisitos. Ok, ok, são muitas perguntas, termos em inglês e você deve estar se perguntando por que deveria fazer esse curso. E eu respondo, se você gosta de software e de engenharia de software, você vai aprender algo novo. Algo que é bastante utilizado no Módulo 5. No módulo 6, nós vamos aprender como visualizar os diferentes níveis de requisitos. E eu respondo, se você gosta de software e de engenharia de software, você vai aprender algo novo. Algo que é bastante utilizado no mercado e pedido em vagas de estágio e até mesmo em concursos públicos. E se você não gosta de engenharia de software e dos métodos ágeis, você vai ter um assunto a mais para poder criticar. Em qualquer caso, seja bem vindo.
